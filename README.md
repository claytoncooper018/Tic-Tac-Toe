# 🎮 Tic Tac Toe (JavaScript)

A simple Tic Tac Toe game built using **JavaScript**, playable directly in the **web browser**.  
The game is fully interactive and dynamically generated using JavaScript logic.

## 🚀 Features
- Two-player gameplay (X vs O)
- Interactive 3×3 board
- Win and draw detection
- Restart game functionality
- Runs entirely in the browser

## 🛠 Technologies Used
- JavaScript
- HTML (minimal, for loading the script)
- CSS (optional / inline styling)
